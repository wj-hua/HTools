# 小纸夹 · Android 剪贴板

一个中文界面的原生 Android 应用，用于保存常用文字、链接和笔记。

## 功能

- 点击右上角「＋」添加内容，只需填写正文。
- 点击卡片或菜单中的「编辑」修改内容。
- 菜单中的「删除」需要确认。
- 一键复制全文到系统剪贴板；编辑页支持从系统剪贴板粘贴。
- 搜索正文内容。
- 浅灰背景、蓝色操作按钮与紧凑卡片，跟随系统切换浅色／深色主题。
- 长按卡片上下拖动排序，靠近列表边缘时自动滚动，松手后保存顺序；菜单也支持「上移」「下移」。
- 搜索结果可以单独调整顺序，其他内容保持原位置；新增内容放在最上方，编辑不改变排序。
- 常用文本继续使用 SQLite 本地持久化。新增独立的云端粘贴板入口，HTTPS 读取 Mac 上传的记录。
- 旋转屏幕保留编辑内容；退出编辑时提醒未保存的修改。

应用通过用户点击「从剪贴板粘贴」读取系统剪贴板，不在后台自动监听。

## 运行

用 Android Studio 打开项目根目录，同步 Gradle 后运行 `app`。

环境要求：JDK 17、Android SDK 35，支持 Android 8.0 及以上。

```sh
./gradlew assembleDebug
```

生成的安装包：`app/build/outputs/apk/debug/app-debug.apk`。

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

使用原生 Java、Android Views、SQLite 与 ClipboardManager，不添加第三方运行时依赖。
构建版本依据 [Android 官方 AGP 8.7 文档](https://developer.android.com/build/releases/agp-8-7-0-release-notes)；
剪贴板行为依据 [Android 官方复制与粘贴文档](https://developer.android.com/develop/ui/views/touch-and-input/copy-paste)。

删除应用或清除应用数据会清空本地记录；本地常用文本不自动上传；云端记录保存于阿里云，可下载到用户选择的位置。

## 跨设备粘贴板（1.1）

首页点击“云端”，在“连接”中粘贴 Mac HTools 页面复制的 Android 配对信息。
连接验证成功后保存到应用私有目录，不随应用备份导出。
进入云端页面自动刷新，前台每 10 秒更新，也可点“刷新云端记录”。

- Mac 复制的文本与图片按最新顺序显示，云端仅保留最新 50 条。
- 文本可一键复制，点正文可查看全文；图片可复制到支持图片粘贴的应用。
- 文本和图片均可通过 Android 系统文件保存窗口下载。
- 下载的文件不受云端清理影响。Android 10+ 复制图片会存入系统“小纸夹粘贴板”相册，最多保留 50 张。Android 8/9 使用私有图片缓存。
- Android 不在后台读取剪贴板，也不自动上传本地记录。
- 复制图片使用原生 ContentProvider 和 URI 授权；无第三方依赖和共享存储权限。

阿里云服务与 Mac 代码位于本仓库根目录，部署说明见 [服务说明](../../server/README.md)。

### 1.1.1 微信图片读取修复

实体手机日志显示，系统剪贴板分享入口转交图片时未将 URI 权限传给微信，
导致微信读取私有图片被拒绝。复制图片时现在为已安装的微信显式授予该张图片的只读 URI 权限，
图片缓存淘汰时撤销授权。Provider 继续不导出，不开放其他文件或写入权限。

已通过 `assembleDebug lintDebug`，更新实体手机并重新复制图片后，
系统权限记录确认 `com.tencent.mm` 获得对应图片的只读访问权限。

### 1.1.2 微信真机兼容修复

显式授权之后微信仍无法处理自定义图片 URI。Android 10+ 改为通过系统 MediaStore
保存分享用 PNG，剪贴板提供系统图片 URI；微信状态编辑和发送给朋友的确认界面都能加载原图。
仅在用户点“复制图片”时保存，存入“小纸夹粘贴板”相册，重复复制同一图片复用资源，
按复制顺序最多保留 50 张，只删除本应用在该相册中创建的缓存图片。
下载到用户指定位置的文件不受缓存清理影响。

已在连接的实体手机完成实际图片预览验证：
微信状态编辑显示该图片；发送给朋友的确认弹窗显示该图片，随后取消。
